# Immersive Voice 沉浸式角色语音

让角色根据战斗、动作和队友行为，自动说出当前声线已有的台词。

**版本：2.16.0（战斗通报测试版） · 作者：ZombiesYard · GPL-3.0-only**

适用于 **SPT 4.1.6 / EFT 0.16.9.40743**，联机接口按 **Fika 2.4.3** 验证。支持单人PMC、Player Scav和最多4名人类玩家的Fika小队。其他版本的兼容性未确认。

[已发布版本](https://github.com/ZombiesYard/ImmersiveVoice/releases) · [安装与设置](#安装) · [日志与反馈](docs/DIAGNOSTICS.md) · [源码构建](docs/BUILD.md) · [更新记录](CHANGELOG.md)

## 能做什么

- **动作与交火反应**：换弹、缺弹、枪械故障、投雷、受伤，以及有对应声库时的治疗提示。
- **可感知的敌情**：首次/再次接敌、敌人方向、确认命中、普通敌对Scav身份、目击敌人倒下和失去视野；后台命中或击杀不会直接变成隔墙播报。
- **队友之间的交流**：根据相对移动、靠拢、停留、同一威胁交火和真实受击等证据，尝试跟随、掩护、推进、后撤、集合、守位、火力突进、散开与寻找掩体。无需先手动发令。回应使用Going、Covering、OnPosition等匹配动作的台词；听到击倒通报可接GoodWork。
- **与 NPC 自动交流**：识别35米内原版讲话通道中的NPC，不按Boss、护卫、AI PMC或Scav角色排除。敌对喊话可引出回骂，未交火的敌人闲聊可引出动静提示；友善请求结合跟随、靠拢、停留或目击后的实际掩护应答。近处平静NPC独白可引出自己的平静独白，不代表固定问候。默认成功回应间隔30秒，同一NPC的90秒窗口内最多回应两次。
- **环境与情绪**：结合原版情境提示处理搜刮、门和撤离等内容，并保留低频平静独白、战斗喊话和战后反应。
- **控制说话时机**：手动喊话优先；有重复冷却和事件过期；背包、菜单、VOIP发言等状态会暂停自动语音。
- **中英文设置菜单**：F12中可以切换本Mod菜单语言，常用设置默认显示，高级参数按需展开。

使用当前角色声线和原版空间音频，不附带游戏音频，也不合成语音。某个声线没有对应片段或当前状态不匹配时保持沉默，不借用其他声线、不改喊另一种含义。

## 本版新增

新增EnemyHit、Scav、ScavDown、严格归属的KnifeKill，以及前后左右敌情。火力与运动组合可触发Gogogo或Suppress；真实受击与三人以上近距拥挤可触发GetInCover或Spreadout。多人客户端使用短暂固定顺序并以实际听见的通报取消后发候选，减少齐喊。每个新语义只使用当前声线的精确音效，没有就略过。

沿用最多四人的固定容量、低频队友采样；没有新增射线或全场扫描。主机仅转发简短的实际播放回执，声音仍走Fika原生同步。已做规则、接口和四客户端模拟，实战听感待验证。

## 安装

1. 退出游戏客户端。
2. 从Releases下载 `ImmersiveVoice-2.15.0.zip`，解压到包含 `EscapeFromTarkov.exe` 的客户端根目录。
3. 确认文件位于 `BepInEx/plugins/ImmersiveVoice/ImmersiveVoice.dll`，然后启动游戏。
4. 如有F12配置菜单，打开 **Immersive Voice** 调整设置；也可以在退出游戏后编辑自动生成的配置文件。

本插件需要客户端已有的BepInEx运行环境。不要将它放入服务端的 `user/mods`。F12图形菜单依赖BepInEx ConfigurationManager；没有该菜单插件时，语音功能仍可加载。

升级时覆盖插件DLL，保留 `BepInEx/config/local.immersivevoice.cfg`。压缩包不附带个人配置，不会替换已有配置。卸载时退出游戏并删除 `BepInEx/plugins/ImmersiveVoice`。

## Fika联机

**主机与全部客户端统一安装2.15.0，不要混用旧版或未安装的客户端。** 每个客户端只驱动自己的角色，声音走Fika原生同步；主机另行协调每次小队来话由谁接话。客户端必须实际听到、行为吻合且有精确音效才申请；收到授权不保证最终发声，原有生存、手动与过期检查仍有效。自定义声线仍需满足其自身的资源要求。

SPT服务端不需要安装；**headless主机需要安装相同版本**，只运行对话协调，不创建角色语音。普通玩家未收到主机能力确认时，不发送自定义包，小队协调回应保持静默，其他独立语音功能继续工作。插件白名单应同步配置 `local.immersivevoice`。

小队关系按最多4名人类玩家设计：每端最多观察三名队友，沿用4Hz动作采样，主机保留四个来话槽。消息仅在来话、申请与授权时发送，不连续同步位置，不增加射线。四人完整实战、所有声线及所有Mod组合仍需更多验证，不承诺零性能开销或固定帧率提升。

## 常用设置

| 设置 | 用途 |
| --- | --- |
| 语言 / Language | 简体中文、English；只影响本Mod菜单 |
| 显示高级设置 | 展开细分冷却、概率和诊断选项 |
| 平静换弹概率 | 非交火换弹的候选概率，默认50% |
| 普通语音间隔 | 控制连续讲话密度，默认8秒 |
| 潜行减少说话 | 默认开启，减少潜行时的非紧急发声 |
| 与 NPC 自动交流 | 独立开关，默认开启；高级设置可调整回应间隔 |
| 本局静默快捷键 | 默认Pause；随时暂停本局自动语音 |
| 保存排查日志 | 默认开启，方便检查没有说话的原因 |

手动Y/F1等原有按键保留。概率调到100%仍需满足语音空闲、动作有效、声库匹配等条件，不表示每次必定播放。菜单默认18项常用设置，展开后另有22项高级设置。

## 已知限制

- NPC后续是否再回答由原版或其他AI插件决定。本插件只控制自己的玩家角色；不识别语音文本、不新增问候素材，也不把NPC惨叫当作击杀确认。未映射的来话仅记日志。第三方脚本绕过原版讲话通道的音频不保证识别。

- PMC、Scav和自定义声线的可用台词不同。当前核验的19套原版玩家声线都没有已注册的 `StartHeal` 片段，因此不能期待每次治疗都有台词；本版本没有启用未登记的治疗录音。
- NPC可听性使用原版音源的音量、距离和遮挡值估计，不等于完整模拟玩家听觉；多人随机延迟和取消机制只能减少齐声回应，不能保证完全消除。NPC互动与小队接话使用不同的协调规则；四人实战仍需验证。
- 长呼吸、正在播放的台词、手动优先、潜行和动作结束可能使事件错过发声窗口。个别语音Mod也可能影响播放。
- 语音是基于行为的沉浸表达，不是精准战术指挥系统；不能代替玩家之间的实际沟通。
- 声音走原版空间播放。需要安静行动时使用静默键，不保证所有AI Mod对语音的反应一致。
- 已完成本地构建、规则/接口、配置与原生挂载验证；自动检查不等于游戏内听音或四人联机验证。
