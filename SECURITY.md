# Security and privacy

Do not attach credentials, personal configurations, save profiles, game assemblies or complete game logs to public reports. Share a minimal reproduction and a reviewed excerpt.

Use GitHub's private vulnerability reporting for security-sensitive reports when available. For ordinary bugs, use the issue tracker with game and plugin versions and a short description of the relevant behavior.

Release packages are distributed through this repository's Releases page. Compare the download against its published SHA-256 file. A matching checksum establishes file identity; it is not a malware verdict.
